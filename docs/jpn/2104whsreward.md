# 報酬

## ランキング報酬

![](https://astrokings.s3.ap-northeast-2.amazonaws.com/html/img/help/2104_01_01.jpg)

各時空間ワームホールのランキングに応じて時空間ワームホール探査トークンが支給されます。

| ランキング順位 | 時空間ワームホール【ロー】 | 時空間ワームホール【ミドル】 | 時空間ワームホール【ハイ】 |
| - | :-: | :-: | :-: |
| 1位 | 2660 | 4760 | 6560 |
| 2位 | 2130 | 4350 | 6230 |
| 3位 | 1750 | 4030 | 5930 |
| 4位 | 1440 | 3750 | 5670 |
| 5位 | 1200 | 3520 | 5460 |
| 6位~10位 | 1010 | 3330 | 5280 |
| 11位~25位 | 850 | 3160 | 5140 |
| 上位20% | 730 | 3030 | 5030 |
| 上位50% | 630 | 2920 | 4950 |
| 上位100% | 550 | 2840 | 4910 |

## 達成報酬

![](https://astrokings.s3.ap-northeast-2.amazonaws.com/html/img/help/2104_03.jpg)

各時空間ワームホールで獲得したワームホールポイントに応じてワームホール報酬トークンが支給されます。

| 達成ポイント | 時空間ワームホール【ロー】 | 時空間ワームホール【ミドル】 | 時空間ワームホール【ハイ】 |
| - | :-: | :-: | :-: |
| 100001~2000000 | 880 | 1970 | 3330 |
| 75001~100000 | 750 | 1810 | 3130 |
| 50001~75000 | 620 | 1650 | 2930 |
| 25001~50000 | 490 | 1490 | 2730 |
| 10001~25000 | 360 | 1330 | 2530 |
| 5001~10000 | 230 | 1170 | 2330 |
| 1000~5000 | 100 | 1010 | 2130 |

## 時空間ワームホールショップ

![](https://astrokings.s3.ap-northeast-2.amazonaws.com/html/img/help/2104_02.jpg)

ランキング報酬として獲得した時空間ワームホール報酬トークンは、ハブ強化材料や様々なアイテムと交換することができます。
